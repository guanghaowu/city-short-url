3我的短链

短码 原始链接 PV / UV
这个页面在验证什么
· 生成短链 → 雪花 ID + base62 → 10 位短码，本地生成无中心化发号器
· 点「打开」→ 服务端 GET /{shortCode} 返回 302，缓存未命中会回源 MySQL 并回填 Redis
· 点「统计」→ PV/UV 来自 access_log 表，该表由 RocketMQ 消费者异步写入（跳转接口不写库）
· 删除是软删（status=2）且会同时清掉 Redis 缓存，否则短链还能跳转
· 别人的短码你查不到：所有管理接口都校验归属，越权返回 403
